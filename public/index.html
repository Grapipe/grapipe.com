Grape + Pipe

포도송이처럼 흩어진 데이터와 반복 업무를 파이프로 이어, 하나의 결과로 모읍니다. 로고의 노드와 선이 그 흐름을 그린 것입니다.

Grapipe는 회사가 아닌 개인이 운영합니다. 처음 이야기를 듣는 사람과 실제로 만드는 사람이 같습니다.

할 수 있는 일

네 가지 영역의 일을 맡습니다. 규모가 작아도 괜찮습니다.

로컬 AI 구축

Local AI

외부 서비스로 데이터를 보내기 어려운 환경을 위한 AI입니다. 오픈 모델을 사내 PC나 서버에 설치하고, 가지고 있는 문서를 검색·요약할 수 있게 연결합니다.

로컬 모델은 대형 클라우드 모델보다 성능이 낮을 수 있습니다. 실제 업무 자료로 먼저 테스트해 보고 진행 여부를 정합니다.

  • 사내 문서 기반 질의응답 (RAG)
  • 외부 반출이 어려운 자료의 요약·분류
  • 보유 장비에 맞는 모델 선정과 설치

Ollama, llama.cpp, vLLM

업무 자동화

Automation

매주 반복되는 복사·붙여넣기, 엑셀 정리, 보고서 작성을 스크립트와 서비스 연동으로 줄입니다.

  • 엑셀·구글 시트 데이터 정리와 집계
  • 웹 데이터 수집, 외부 API 연동
  • 메일·메신저 알림, 정기 보고서 자동 생성

Python, Apps Script, n8n

바이브 코딩

Vibe Coding

AI 코딩 도구로 아이디어를 빠르게 동작하는 형태로 만듭니다. AI가 작성한 코드도 직접 읽고 검토한 뒤 전달합니다.

  • 아이디어 검증용 프로토타입·MVP
  • AI로 만들다 막힌 프로젝트의 점검과 정리
  • AI 코딩 도구 개발 환경 세팅과 사용법 안내

Claude Code, Cursor, Codex

기획부터 배포까지

End-to-end Development

요구사항 정리, 화면 설계, 개발, 배포, 운영 이관까지 한 사람이 처음부터 끝까지 맡습니다.

  • 웹사이트, 랜딩 페이지
  • 웹 서비스, 관리자 페이지, 내부 도구
  • 서버·도메인·배포 환경 구성

TypeScript, React, Node.js, Cloudflare

진행 방식

문의부터 전달까지, 각 단계에서 무엇을 하는지 미리 알려드립니다.

  1. 1

    문의

    지금 상황과 원하는 결과를 메일로 알려주세요. 정리되지 않은 상태여도 괜찮습니다.

  2. 2

    상담

    필요한 것과 필요하지 않은 것을 함께 구분하고, 작업 범위를 정합니다.

  3. 3

    견적과 일정

    범위, 비용, 일정을 문서로 정리해 확인받은 뒤 시작합니다.

  4. 4

    개발

    중간 결과를 공유하며 진행합니다. 방향이 다르면 일찍 바로잡습니다.

  5. 5

    전달

    결과물과 함께 사용 방법, 운영에 필요한 내용을 정리해 전달합니다.

  6. 6

    이후 (선택)

    필요하면 수정과 유지보수를 이어서 맡습니다.

중간 전달자 없이, 이야기를 나눈 사람이 설계하고 코드를 작성합니다.

할 수 있는 만큼만 약속합니다

맞지 않는 일이거나 일정이 어렵다면 시작하기 전에 먼저 말씀드립니다.

동시에 많은 일을 받지 않습니다

진행 중인 작업에 따라 시작 시점을 조율해야 할 수 있습니다.

이후에도 관리할 수 있게 넘깁니다

소스코드와 설정 방법, 운영에 필요한 문서를 함께 전달합니다.

자주 묻는 질문

아주 작은 작업도 문의해도 되나요?

네. 엑셀 정리 스크립트 하나, 간단한 페이지 하나도 괜찮습니다.

비용은 어떻게 정해지나요?

작업 범위와 기간에 따라 달라서 정해진 가격표는 두지 않았습니다. 상담으로 범위를 정한 뒤 견적을 드립니다.

로컬 AI를 쓰려면 장비가 따로 필요한가요?

쓰려는 모델의 크기에 따라 다릅니다. 가지고 계신 PC·서버 사양을 먼저 확인하고, 그 안에서 가능한 방법과 추가 장비가 필요한 경우를 나눠 안내합니다.

개발을 잘 몰라도 괜찮을까요?

괜찮습니다. 원하는 결과를 말씀해 주시면, 기술적인 선택은 이유와 함께 설명드립니다.

회사가 아니라 개인이면 무엇이 다른가요?

한 사람이 처음부터 끝까지 맡기 때문에 소통 단계가 짧습니다. 대신 동시에 맡는 일이 적어, 문의 시점에 따라 일정 조율이 필요할 수 있습니다.
